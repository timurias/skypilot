# АРХИТЕКТОР АСУ БВС

Интегрированная среда проектирования, симуляции и дообучения автономных систем управления БПЛА.

## Настройка локальных ресурсов

Для работы симулятора и планировщика необходимо разместить файлы в папке `public` в корне проекта.

### Список необходимых файлов:
- `public/map.png` — Карта миссии (PNG).
- `public/mt.gif` — Анимация мультироторного БПЛА.
- `public/st.gif` — Анимация самолетного БПЛА.
- `public/svvp.gif` — Анимация СВВП (VTOL) БПЛА.
- `public/videos_simulations/Map_view.webm` — Вид сверху на симуляцию.
- `public/videos_simulations/Depth_map.webm` — Визуализация карты глубин.
- `public/videos_simulations/Sensors.webm` — Кластер данных датчиков.
- `public/videos_simulations/Lidar.webm` — Облако точек лидара.
- `public/videos_simulations/rgb_view.mp4` — Основной поток RGB камеры.

## Структура приложения
1. **Платформа и функционал**: Настройка планера, полезной нагрузки и выбор алгоритмов управления (классические/НС).
2. **Планировщик**: Разметка маршрутов и запретных зон на карте с помощью ИИ.
3. **Симулятор**: Синхронное воспроизведение потоков данных в реальном времени.
4. **Дообучение**: Анализ телеметрии и получение рекомендаций по дообучению моделей.
